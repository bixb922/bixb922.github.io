Pinout file generator
This web page aids to generate a pinout file template for the crank organ software that reflects your hardware structure. Provide the information, then copy the resulting pinout with the "Copy to clipboard" button below and save in a file on your PC using a text editor like Notepad (Windows) or TextEdit (Mac). Then upload the resulting file to the microcontroller. Select the file in the Pinout and MIDI Configuration page, and fill out the rest of the information, i.e. mainly the MIDI notes.
